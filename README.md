# IS601 Module 2 Calculator Project

This project is a simple Python command-line calculator created for IS601.

## Features

The calculator supports:
- Addition
- Subtraction
- Multiplication
- Division

The application uses a REPL-style command-line interface and includes automated tests using pytest.

## Run the Calculator

```bash
python3 main.py

## Run Tests

pytest

## Continuous Integration

GitHub Actions automatically runs the pytest test suite whenever code is pushed to the main branch.
